Entry for the make.fun **Real-Life Patch Notes: The Comedy Changelog**: one
original one-line patch note for a bug in real life or human biology, at most
160 characters, judged pairwise by an AI comedy editor.

- `main.ts` — the entrypoint. Writes the patch note to `/output/entry.txt`.

The entry:

> v2.2.2: fixed a bug where the brain kept every lyric from 2007 but forgot why it opened the fridge.
